# **SaveUs – Blood Donation Mobile Application**

---

## **About the Application**

SaveUs is a mobile application developed to simplify and improve the blood donation process during emergency situations. In many cases, people share urgent blood requests through social media platforms such as WhatsApp, Instagram, or Facebook. These methods often lead to delays, uncontrolled message circulation, and difficulty in finding eligible donors quickly.

SaveUs solves this problem by providing a dedicated platform where blood requests can be sent instantly to all registered users. The application ensures faster communication between donors and recipients while also verifying whether a donor is medically eligible to donate blood.

The system integrates mobile application technology with artificial intelligence to improve the reliability and efficiency of the blood donation process.

---

## **Application Workflow**

### **1. User Registration**

New users register in the application by providing their basic details such as name, email, phone number, blood group, age, and other required information. This information is securely stored in the cloud database.

### **2. Login and Profile Setup**

After registration, users can log into the application and manage their profile. The profile stores important information such as blood group, age, and health details that help determine donor eligibility.

### **3. Blood Request Creation**

When a person needs blood, they can create a request by filling out details such as the required blood group, hospital location, reason for the request, and the deadline for donation. Once submitted, the request is stored in the database.

### **4. Real-Time Notification**

As soon as a request is created, notifications are sent to all registered users of the application. This ensures that potential donors are informed immediately, reducing delays in emergency situations.

### **5. Viewing Requests**

Users can view all active blood requests within the application. Each request includes important information such as requester details, blood group required, and hospital location.

### **6. Donor Eligibility Verification**

Before accepting a request, donors must pass an eligibility check. The system verifies whether the donor meets the necessary conditions for blood donation. The eligibility check includes age verification, weight requirement, health condition within the last two days, blood group compatibility, and hemoglobin level prediction.

### **7. Hemoglobin Level Prediction**

The application uses a deep learning model to estimate hemoglobin levels from conjunctiva eye images. This helps determine whether the donor is medically fit to donate blood.

### **8. Accepting a Request**

If the donor satisfies all eligibility criteria, they can accept the request. Once accepted, the request status is updated in the system.

### **9. Request Completion**

When the required number of donors accept the request, the system automatically closes the request. This prevents unnecessary notifications and ensures that requests do not continue circulating after they are fulfilled.

---

## **Key Idea Behind the Application**

The main objective of SaveUs is to replace inefficient social media blood requests with a structured and intelligent system that provides faster communication between donors and recipients, real-time request notifications, verification of donor eligibility, automatic request management, and reliable coordination during medical emergencies.

---

## **Impact of the Application**

By combining mobile technology, cloud services, and artificial intelligence, SaveUs helps create a more organized and effective blood donation ecosystem. The application aims to reduce response time during emergencies and ensure that only eligible donors participate in the donation process.
