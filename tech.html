Technology

Built With a Modern Stack

SaveUs is powered by production-grade technologies chosen for reliability, speed, scalability, and cross-platform reach.

Frontend

Mobile Application

🐦
Flutter
Cross-platform mobile framework that builds native Android and iOS apps from a single codebase with a fast, responsive UI.
🎨
Dart
The programming language used with Flutter. Provides fast compilation and a clean, expressive syntax for building rich UIs.
Backend & Database

Firebase Services

🔐
Firebase Authentication
Manages secure user registration and login using email/password. Ensures only verified users can access the application.
🔥
Cloud Firestore
NoSQL real-time cloud database storing user profiles, blood requests, and all app data with instant synchronization.
📨
Firebase Notifications
Powers the real-time push notification system that alerts all registered users when a new blood request is created.
Artificial Intelligence

AI & Machine Learning

🧠
TensorFlow
Open-source deep learning framework used to train and deploy the hemoglobin prediction model.
⚗️
Keras
High-level neural network API running on TensorFlow. Used to build and train the CNN model for eye image analysis.
🐍
Python
The programming language used for developing and training the deep learning model.
📊
CNN Architecture
Convolutional Neural Network trained to detect hemoglobin level patterns from conjunctiva eye images.
Distribution

Platform & Release

🤖
Android APK
SaveUs is distributed as an Android APK (v1.0). Install directly on any Android device.
🐙
GitHub Releases
The app is hosted on GitHub Releases for easy and reliable APK distribution to end users.
